Getting started

Installed in three steps

If you've ever installed a Forge mod, you already know how this goes.

Install Forge 1.8.9

Run the Forge installer for 1.8.9, then start the game once so the profile is created.

Drop in the jar

Download FrostClient from Modrinth and put the jar in your mods folder.

Launch and open the menu

FAQ

Questions, answered straight

Is FrostClient a hacked client?

No. FrostClient ships quality-of-life and performance modules — counters, HUD widgets, render tweaks and FPS work. It doesn't include combat automation or anything designed to break a server's rules. Whether a specific module is allowed is still your server's call, so check their rules before you play.

Does it collect any data?

No accounts, no analytics, no phone-home. That's the reason the project exists — and because the client is open source under LGPL-3.0, you don't have to take our word for it.

Will it work with my other Forge mods?

That's the intent. FrostClient uses a crash-safe Mixin architecture specifically so it can sit alongside other Forge mods instead of replacing your whole install. If you hit a conflict, open an issue with your log.

Which Minecraft versions are supported?

1.8.9 only, for now. The 1.7.10 and 1.12.2 trees haven't been ported from the original CloudClient source yet — if you want to take one on, the repository is open.

Can I fork it or reuse the code?

Yes. FrostClient is licensed under the GNU LGPL v3.0, so you can modify and redistribute it as long as you disclose your source. It's forked from CloudClient and credits superblaubeere27, LaVache-FR and Moulberry.

How do I build it myself?

Clone the repository, move into the folder for your target version, run gradlew setupDecompWorkspace idea (or eclipse), then gradlew build. The compiled jar lands in build/libs.

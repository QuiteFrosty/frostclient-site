Install guide

Manual install, step by step

Four steps, no launcher involved. If you already run Forge mods, skip to step three.

Install Forge 1.8.9

Grab the 1.8.9 installer from the official Forge site, run it in Install client mode, then launch the game once on the new Forge profile so the folders are created.

Open your mods folder

Create the folder if it isn't there yet.

Windows %appdata%\.minecraft\mods
macOS ~/Library/Application Support/minecraft/mods
Linux ~/.minecraft/mods

Drop in the jar

Move the FrostClient jar into that folder. Leave your other 1.8.9 Forge mods where they are — FrostClient is built to run beside them.

Launch and configure

Start Minecraft on the Forge 1.8.9 profile, press Right Shift for the mod menu, then open the HUD editor to lay out your widgets.

Server rules still apply. FrostClient ships quality-of-life and performance modules, but every network draws its own line — check what your server allows before you enable things.

Trouble?

If it doesn't launch

The game crashes on startup

Check that you're on the Forge 1.8.9 profile and running Java 8 — a mismatched Minecraft or Java version is the usual cause. If it still crashes, open an issue and attach the crash report from .minecraft/crash-reports.

FrostClient doesn't show up in game

Confirm the jar is in the mods folder of the profile you actually launched, and that it isn't still zipped or renamed to .jar.zip by your browser.

It conflicts with another mod

FrostClient uses a crash-safe Mixin setup to coexist with other Forge mods. If something still breaks, report it with your log and the list of mods you're running — conflicts are treated as bugs.
